# ZuluFun.io Blueprint

## Overview
ZuluFun.io is an autonomous, AI-powered business platform for Africa. It combines a Business Insider-style news portal with a Lead Generation marketplace.

## Current State
- Next.js 14 App Router project setup.
- Basic styling (Tailwind, globals.css) and design tokens applied.
- Homepage (`/app/page.tsx`), Auth routes, Layout components implemented.
- News section (`/app/news`) and components built.

## Missing/Pending Implementation Steps
- Create `/quotes` and `/quotes/[niche]` form pages.
- Create `/products` and product subpages (`leadai`, `adai`, `audit`, `api`).
- Create `/b2b` and B2B niche marketplaces.
- Create `/ai`, `/bespoke`, `/investors`, `/about` pages.
- Build Dashboards (`/dashboard/consumer`, `/dashboard/business`, `/dashboard/admin`).
- Implement API routes (`/api/v1/leads`, `/businesses`, `/analytics`, `/webhooks`).
